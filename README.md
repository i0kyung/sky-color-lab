# 하늘 연구소 (Sky Color Lab)

하늘은 왜 그런 색일까? 하늘의 색을 만드는 **대기 광학** 원리를 두 가지 게임으로 배우는 지구과학 교육용 웹 게임입니다.

## 게임
- **🌤️ 하늘의 색** (`하늘의색.html`) · 추론 퀴즈
  - 구름을 눌러 관측 데이터(시간대·태양 고도·습도 등)를 보고, 하늘 색을 만든 원리를 고릅니다.
  - 입문 → 중급 → 하드 3단계, 12가지 현상. 오답마다 왜 틀렸는지 설명이 나옵니다.
  - 맞히면 원리대로 하늘이 반응하고(산란·굴절·발광 이펙트), 원리 요약이 무대에 남습니다.
- **🎨 하늘 팔레트** (`하늘팔레트.html`) · 조합 게임
  - 상황을 읽고 대기 원인(맑은 공기·긴 통과거리·물방울·약해진 햇빛·먼지·연기·대기 발광)을 골라 하늘을 직접 만듭니다.
  - 연습 · 일반 · 챌린지(제한 시간) 모드, 별점과 하늘 도감.

## 학습 내용
- 레일리 산란(∝ 1/λ⁴)과 파란 하늘 · 대기 통과 거리와 노을 · 블루 아워와 오존 흡수
- 미 산란과 흰 구름·안개 · 두꺼운 구름의 빛 감쇠
- 에어로졸: 황사(산화철의 파랑 흡수), 산불 연기(파장 크기 입자의 선택적 소광)
- 굴절·분산: 무지개(빨강 약 42°·보라 약 40°), 22° 무리(육각 빙정)
- 대기 발광: 오로라(산소·질소)
- 확정되지 않은 현상(초록빛 폭풍 하늘)은 '가설'로 구분해 소개합니다.

과학 서술은 간단한 물리 모델(에어매스, 레일리 광학두께, Mie 계산, 오존 흡수, 굴절 최소편각)로 수치를 점검했습니다.

## 실행 방법
웹에서 바로 플레이: https://i0kyung.github.io/sky-color-lab/

브라우저에서 `index.html`을 열거나, 로컬 서버로 실행한 뒤 `http://localhost:8000`에 접속하세요.

    python -m http.server

- 외부 라이브러리 없는 단일 HTML (글꼴만 Pretendard CDN)
- 효과음은 Web Audio로 실시간 합성합니다(음원 파일 없음). 각 게임의 🔊 버튼으로 끌 수 있습니다.
- 기록은 브라우저(localStorage)에만 저장됩니다.
- `prefers-reduced-motion`(동작 줄이기) 설정을 지원합니다.
